01 · Requirements

要件

既存の性格診断（MBTI 等）は「内面」を測ることに重点を置いているが、職場・学校・初対面などの場面では「人前で出す自分（仮面）」と本来の自分にギャップがあることが多い。MTPA は、この「外面性格」のみを切り出して可視化することで、コミュニケーション改善・チームビルディング・自己理解を実用レベルで支援することを要件とする。

REQ-01

対象は「外面の自分」のみ

家族・親友の前ではなく、学校・職場・初対面の場での振る舞いに限定して質問を設計。心理学＋統計学に基づき外面行動を構造化する。

REQ-02

5分以内で完結する負荷

40問（5問×8ページ）の6段階リッカート回答。直感的に答えても精度が出るよう、軸が明確に分離した質問群を採用。

REQ-03

完全無料・登録不要

会員登録、個人情報の入力を一切要求しない。「診断を始める」のクリック=利用規約への同意として運用。

REQ-04

医療・臨床診断ではない明示

自己理解の参考情報を提供するエンタメ・自己分析サービスとして位置づけ、医学的・臨床的評価ではないことを免責表示。

REQ-05

匿名統計の蓄積と改善

回答内容・結果・フィードバックは匿名でDB保存し、サービス改善と統計分析に利用。IP・氏名・メール等の特定情報は保存しない。

REQ-06

SEO・OGP最適化

「16タイプ」「外面性格診断」「仮面診断」「ヴェール診断」等の検索流入を想定。OGP/JSON-LD（ItemList, FAQPage）でリッチリザルト対応。

02 · Features

機能の説明

4つの独立した観察軸を設定し、それぞれの軸で2つのポール（特性）に分類する。4軸を組み合わせることで 24＝16タイプ の「仮面」が生成される。各タイプはMBTI風の4文字コード（例: SFCP, MFGQ）で表現され、強み・弱み・職場での傾向・コミュニケーションスタイル・相性などの詳細を提示する。

主な機能

F-01

40問の診断フロー

5問×8ページのステッパー形式。6段階リッカートで回答負荷を抑え、戻る/進む両対応。途中保存なし＝5分で完了するUX前提。

F-02

タイプ自動算出

4軸それぞれをスコア化し、しきい値で2極化。S/M, F/B, C/G, P/Q の4文字コードを生成し、対応する仮面タイプを返す。

F-03

結果ページ・タイプ詳細

4文字コード + 「○○仮面」の名前 + 一言要約（shortLabel）+ 強み・弱み・仕事傾向・コミュニケーション特性を構造化して提示。

F-04

16タイプ一覧 / Type List

全16タイプの比較閲覧。各タイプにアイコン画像・短評・軸サマリ（tension/position/distance/work）を表示。

F-05

SNSシェア・OGP動的画像

結果ページにシェアボタンを配置。OGP画像は SVG ベースで生成し、各タイプごとに表示が変わる仕組み。

F-06

Note（コンテンツ記事）

/note 配下に「タイプ別の活かし方」「コミュニケーション改善Tips」等のコンテンツ。検索流入とリピート訪問を両立。

04 · Production

プロダクション説明

本番運用中の公開ウェブアプリケーション。Syntheraのサブドメイン masktype.synthera.jp でホスティングし、Cloudflare の前段で配信。React + Viteベースの SPA で、コード分割によりページ単位で JS を遅延ロードしている。

P-01

公開URL

masktype.synthera.jp
Synthera ブランドのサブドメインで運用。

P-02

技術スタック

React 18 + Vite + React Router。Tailwind ベースのスタイリング。アクセシビリティ・SEO（OGP / JSON-LD ItemList / FAQPage）対応。

P-03

配信・CDN

Cloudflare 経由で配信。Cloudflare Insights による匿名アクセス計測。静的アセットはチャンク分割し各ページ単位で遅延ロード。

P-04

アナリティクス

Google Analytics 4（G-EHC6XC46PM）をロード後に遅延注入。LCPに影響を与えない非同期ロード方式。

P-05

サイト構成

Top / Diagnose / Result / Type List / Type Detail / Note / FAQ / About / Privacy / Terms / Disclaimer の11ページ構成。

P-06

運営方針

個人情報非収集の完全匿名・無料運用。MBTI等の既存診断とは無関係であることを明示。医療診断ではないことを Disclaimer で明示し、エンタメ・自己理解の補助ツールとして提供。
